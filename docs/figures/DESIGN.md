## Style Prompt
Academic technical diagrams for a robotics bachelor's thesis. Clean, precise, print-ready.
White background, dark navy type, steel-blue accents. Every element must remain legible
at 14 cm printed width. No decorative flourishes — clarity is the only metric.

## Colors
- `#FFFFFF` — page background
- `#1E2B3C` — primary text, box outlines
- `#EEF4FB` — box fill (matches diploma table header tint)
- `#2D6A9F` — box border, connector lines
- `#2965B5` — arrows, arrowheads, highlights
- `#1E3A5F` — controller/master box fill
- `#5A6A7A` — secondary labels, annotations

## Typography
- System sans-serif: -apple-system, 'Segoe UI', Arial, sans-serif
- Scene title: 26px / 600 weight
- Box title: 20px / 700 weight
- Box subtitle: 16px / 400 weight
- Annotations: 18px / 400 weight

## What NOT to Do
- No gradients (H.264 banding risk; irrelevant here but still bad for print)
- No shadows (muddies print reproduction)
- No rounded corners larger than 8px
- No font sizes below 16px (illegible at 14 cm printed width)
- No pure black `#000000` — use `#1E2B3C` for a softer, academic look
