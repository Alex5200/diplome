# TODO: Реструктуризация проекта (Модульная архитектура)

Этот документ описывает шаги по переходу к архитектуре "Core-First", где центральная логика (кинематика, интерфейсы, конфиги) отделена от реализаций (ROS2, Web, GUI).

## 1. Стабилизация Ядра (`core/`)
- [ ] **Самостоятельный пакет**: Создать `pyproject.toml` в папке `core/`, чтобы его можно было устанавливать через `pip install -e ./core`.
- [ ] **Менеджер конфигурации**: Перенести логику загрузки `robot_config.json` из `app/` в `core/config_manager.py`.
- [ ] **Тесты ядра**: Перенести unit-тесты кинематики из `app/tests/test_kinematics.py` в `core/tests/`.
- [ ] **Документация Core**: Описать математическую модель и DH-параметры в `core/README.md`.

## 2. Разделение модулей (Isolation)

### ROS2 App (`ros2/`)
- [ ] **Зависимость от Core**: Обновить `setup.py` в ROS2, чтобы он требовал установленный пакет `core`.
- [ ] **Очистка импортов**: Полностью исключить зависимости от папки `app/` (Desktop GUI).
- [ ] **Hardware Interface**: Реализовать `core.interfaces.IMotorController` внутри ROS2 ноды.

### Web App (`web/`)
- [ ] **Backend**: Перевести FastAPI роуты на использование `core.kinematics`.
- [ ] **Frontend**: Синхронизировать `web/frontend/src/utils/kinematics.ts` с изменениями в `core/kinematics.py`.
- [ ] **Docker**: Настроить сборку так, чтобы контейнер подтягивал `core/` как общую библиотеку.

### Desktop App (`app/`)
- [ ] **Рефакторинг**: Переименовать корень `app/` в `desktop/` для ясности.
- [ ] **GUI Separation**: Убедиться, что PySide6 интерфейс не содержит логики кинематики, а только вызывает методы из `core`.

## 3. Git-стратегия (Ветки)
- [ ] **Подготовка `main`**: Оставить в `main` только `core/`, `shared/` и файлы инфраструктуры (Docker, Makefile).
- [ ] **Создание веток**:
    - `git checkout -b feature/ros2-app` (перенос и настройка ROS2 компонентов)
    - `git checkout -b feature/web-app` (перенос и настройка Web компонентов)
    - `git checkout -b feature/desktop-app` (перенос и настройка GUI компонентов)
- [ ] **Workflow**: Все изменения в базовой математике (кинематике) сначала вносятся в `main`, затем вливаются в остальные ветки.

## 4. Завершение очистки
- [ ] **Удалить дубликаты**: Проверить и удалить неиспользуемые копии `kinematics.py` в других папках.
- [ ] **CI/CD**: Настроить проверку импортов, чтобы предотвратить появление перекрестных зависимостей между модулями.
